1. Vigía とは

Vigía は Windows 用の Markdown ビューアー兼エディターです。見出し、太字、リスト、表、コードなどの書式をボタンで付けると、 Markdown のタグは Vigía が裏で書きます。どの文書も、GitHub での表示とまったく同じように、ライトまたはダークのテーマで表示されます。

README.md、メモ、ドキュメントなど、記法を覚えずに読んだり編集したりしたいあらゆる .md ファイルのために作られています。

2. インストール

Vigia-Setup-3.5.3.exe を実行します。インストーラーは英語、スペイン語、日本語に対応しており、管理者権限は不要です。 現在のユーザー用に %LOCALAPPDATA%\Programs\Vigia へインストールします。

オプション内容
デスクトップ上にアイコンを作成するデスクトップに Vigía のアイコンを置きます。
.md ファイルを Vigía で開く.md / .markdown ファイルの［プログラムから開く］に Vigía を加え、現在のユーザーでそれらのファイルを開くプログラムにします。
エクスプローラーのフォルダーに「Vigía で開く」を追加するエクスプローラーでフォルダー（またはフォルダー内の何もない所）を右クリックすると、ファイル パネルで開けます。Windows 11 では［その他のオプションを確認］の中にあります。

動作環境: Windows 10 または 11（64 ビット）と Microsoft Edge WebView2 ランタイム（Windows 11 には最初から入っています）。 .NET ランタイムは同梱されているので、ほかに何もインストールする必要はありません。

バージョン 1.1.1 までは Quillforge、2.2.1 までは Gryphmark という名前でした。どちらかがインストールされていればインストーラーが削除し、 Vigía は最初の起動時に設定、最近使ったファイル、復元用の下書きを引き継ぎます。

アンインストール: 設定 → アプリ → インストールされているアプリ → Vigía → アンインストール。 %APPDATA%\Vigia の設定は残ります。

3. ウィンドウ

部分用途
メニュー バーファイル、編集、書式、表示、言語、ヘルプ。すべてのメニューは英語、スペイン語、日本語で使えます。
ツール バー新しい Markdown ファイルと新しいフォルダー、ファイル・目次・検索の各パネルを表示するボタン、そして書式のボタン（後述）。書式のボタンは GitHub プレビューと読み取り専用では灰色になります。右側には自動保存スイッチ、編集 | 読み取り専用、3 つの表示、レイアウト ボタンがあります。
タブ開いている文書ごとに 1 つ（「タブ」の章を参照）。
文書ページそのもの。github.com と同じ列幅、フォント、行間でレイアウトされます。
ステータス バーファイルのパス、語数、現在の表示、保存していない変更があるかどうか、そしてズーム バー。

タイトル バーにはファイル名が表示されます。前に ● が付いているときは、保存していない変更があります。

4. 文書の 3 つの表示

ツール バー右端の 3 つのボタン — ビジュアル · Markdown · GitHub —、表示メニュー、またはショートカットで切り替えます。ボタンにポインターを合わせると説明が出ます。

ボタンショートカット見えるもの
ビジュアル
ビジュアル エディター		Ctrl+1書式付きの文書。入力してボタンを使えば、Markdown は自動で作られます。
Markdown
Markdown ソース		Ctrl+2左に Markdown のテキスト、右にリアルタイムのプレビュー。タグを見たり直したりしたいときに。
GitHub
GitHub プレビュー		Ctrl+3GitHub と同じように表示される読み取り専用のページ。コードの色分け、タスク リスト、クリックできるリンク付き。

読み取り専用

文書を読むだけのときは、表示ボタンの左にある編集 | 読み取り専用の切り替えで読み取り専用を選びます （表示 → 読み取り専用、または Ctrl+Shift+L でも可）。どの表示でもテキストがロックされ、キー入力、貼り付け、ドラッグ アンド ドロップ、 タスクのチェック ボックスは効かなくなり、書式ボタンは灰色になります。読む、選択する、コピーする、検索する、表示を切り替えることはできます。 入力しようとすると、ステータス バーにロックの解除方法が表示されます。また書くには編集を選びます。選んだ状態は記憶されます。

5. タブ

Vigía は1 つのウィンドウで複数の文書を、本文の上の帯にタブとして 1 つずつ並べて開きます。タブごとに専用のエディターがあるので、 別のタブを見ている間も、元に戻す履歴、カーソル、スクロール位置はそのまま残ります。保存していない変更があるタブには点が付きます。 タイトル バーとステータス バーは表示中のタブの文書を示し、目次もそれに合わせて変わります。

操作方法
ファイルをタブで開くファイルを開くあらゆる方法: ファイル パネルでのクリック、お気に入り、ファイル → 開く…（複数のファイルを一度に選ぶと、それぞれがタブになります）、最近使ったファイル、検索結果、.md へのリンク、ウィンドウにドロップしたファイル、エクスプローラーから開いたファイル。すでに開いているファイルは二重には開かず、そのタブを表示します。新しいタブは表示中のタブの隣に入ります。表示中のタブが空の無題の文書（または手を付けていないサンプル）なら、タブを増やさずにそこへ開きます。
プレビュー タブファイル パネル（またはお気に入り、最近使ったファイル）でファイルをクリックすると、名前が斜体の一時的なタブに表示されます。次にそこでクリックしたファイルが同じタブに入れ替わるので、フォルダーを見て回ってもファイルごとにタブが増えません。入力するか、ファイルまたはタブをダブルクリックすると、通常のタブとして残ります。ほかの方法で開いたファイルは通常のタブになります。ファイル → パネルのファイルをプレビュー タブで開くでオフにできます（既定はオン）。
新しいタブCtrl+N、ファイル → 新しいタブ、または帯の右端の +: 無題の文書です。
切り替えタブをクリックするか、Ctrl+Tab / Ctrl+Shift+Tab（Ctrl+PageDown / Ctrl+PageUp でも可）。収まりきらなくなったら、帯の上でマウス ホイールを回すとスクロールし、⌄ ボタンですべてを一覧できます。
閉じるCtrl+W、ファイル → タブを閉じる、タブの ×、またはタブの中クリック。保存していない変更があるタブは先に確認します（自動保存がオンなら、名前のあるファイルはそのまま保存されます）。最後のタブを閉じると、空の無題の文書が残ります。Ctrl+Shift+T（ファイル → 閉じたタブを開き直す）で最後に閉じたタブが戻ります。
移動タブを帯に沿ってドラッグします。
タブの右クリックタブを閉じる、ほかのタブを閉じる、右側のタブを閉じる、すべてのタブを閉じる、閉じたタブを開き直す、パスをコピー、フォルダーに表示、起動時にタブを復元。

ウィンドウを閉じるとすべてのタブが閉じます。保存していない変更があるタブは順に表示して確認し、キャンセルを選ぶとウィンドウは開いたままです。 次回また同じタブで始めたいときは、ファイル → 起動時にタブを復元をオンにします（既定はオフ）。次回の起動時に、同じファイルが同じ順序で開き、 同じタブが表示されます。一覧はタブが変わるたびに記録されるので、異常終了や停電のあとでも残ります。無題の文書は記録されず、 その時点で存在しないファイルは除かれます。専用インスタンスはそれぞれ自分のタブを記憶し、追加のウィンドウ（ファイル → 新しいウィンドウ）が メイン ウィンドウのタブを上書きすることはありません。

表示の設定はすべてのタブで共通です: 表示モード、読み取り専用、本文の幅、スペル チェック、テーマ、言語、ズーム。見ていないタブは、 次に表示したときに変更が反映されます。隠れているタブのファイルをほかのプログラムが変更すると、そのタブを表示したときに再読み込みします （保存していない変更があれば確認します）。ファイル パネルでファイルの名前を変えたり移動したりすると、タブもそれに付いていきます。

6. フォルダー: ファイル パネル

VS Code や Obsidian のように、Vigía はフォルダーを左側にツリーとして表示します: サブフォルダーと Markdown ファイル （.md、.markdown）。複数のフォルダーを同時に開けます。それぞれが自分のパステル カラーと左端の帯を持つブロックになるので、 どこで 1 つのツリーが終わり次が始まるのかがひと目でわかります。ファイルをクリックすると、ツリーの横に開きます。

操作方法
フォルダーを開くパネルの + ボタン、ファイル → フォルダーを開く…、空のパネルのフォルダーを開く…ボタン、ウィンドウへのフォルダーのドロップ、またはエクスプローラーでフォルダーを右クリック → Vigía で開く（インストーラーのオプション。Windows 11 では［その他のオプションを確認］の中）。新しいフォルダーはほかのフォルダーの下に加わります。
パネルの表示 / 非表示Ctrl+Shift+E、ツール バーのフォルダー ボタン（3 番目）、または表示 → ファイル パネル。サイド バーを目次と分け合い、上がファイル、下が目次です。サイド バーの右端をドラッグすると幅が、2 つの間の線をドラッグするとそれぞれの高さが変わり、どちらも記憶されます。専用インスタンスはそれぞれ自分のレイアウトを記憶します。
レイアウトツール バー右端のレイアウト ボタンは、現在のレイアウトを描いた小さな図です。クリックすると 6 つのレイアウトを描いたパネルが開きます: ファイルと目次を左に（上下または左右）、本文の両側に 1 つずつ（どちら向きでも）、または両方を右に。図をクリックするとすぐに適用されます。その下のファイル、目次、検索でそれぞれのパネルをオン / オフし、ファイルと目次を入れ替えるで位置を入れ替えます。表示 → レイアウトにも同じ選択肢があります。レイアウトごとにサイド バーの幅を記憶するので、端をドラッグすればそのレイアウトが覚えます。
パネルはタイトル（ファイル、目次、検索）をつかんでウィンドウの端までドラッグすることもできます。ドラッグ中は両端が囲まれ、パネルが入る場所が名前付き（目次を右に、ファイルを目次の下になど）で塗られます。もう一方のパネルの近くでは、上の部分なら上に、下の部分なら下に、中央なら横に置きます。離すと移動します。ウィンドウの中央で離すか Esc を押すと、何も変わりません。
たどるフォルダーをクリックすると開閉し、ファイルをクリックすると開きます。選んだ行で Enter を押しても同じです。
お気に入りファイルとフォルダーの各行の右端に星があります。ポインターが行の上にあると薄く、お気に入りなら金色で塗られます。星をクリックする（または右クリック → お気に入りに追加、開いているファイルならファイル → お気に入り）と、パネルの最初のブロックお気に入りに加わります。開いているすべてのフォルダーに共通の一覧で、各ファイルのフォルダーが灰色で添えられます。お気に入りのフォルダーが先に並び、ツリーのように開きます。お気に入りを別のお気に入りの上にドラッグすると並べ替えられます（右クリック → 上へ / 下へ移動、削除も可）。ブロックのタイトルを右クリックすると、A → Z に並べ替え、存在しないファイルの削除、一覧を空にする、ができます（ファイル自体には触れません）。パネルで名前を変えたり移動したりしたお気に入りは、ファイルに付いていきます。お気に入りから開いたファイルでは、フォルダーのツリーはそのままです（展開もスクロールもしません。フォルダーから開いた場合はツリーが追従します）。
フォルダー内を検索表示 → フォルダー内を検索、ツール バーの虫めがね、または Ctrl+Shift+F で検索パネルが出ます。2 文字以上入力すると、入力が止まって少ししてから、開いているフォルダーのすべての Markdown ファイル（ツリーに表示されるファイル）を検索します。結果はファイルごとにまとめられ、各行に行番号と太字の一致箇所が付きます。クリックするとファイルのその一致箇所を開き、検索バーにも表示されます。Aa で大文字と小文字を区別します。検索は 300 ファイルまたは 5,000 件で止まります（その旨が表示されるので、語句を絞り込んでください）。ほかと同じパネルなので、レイアウト ボタンやタイトルのドラッグで配置できます。
最近使ったファイル既定ではオフ。表示 → パネルに最近使ったファイル（またはパネルの ⋯ メニュー）で、お気に入りの下に、最後に開いた 8 ファイルの最近使ったファイルブロックが加わります。
フォルダーのタイトルを右クリック新しい Markdown ファイル…と新しいフォルダー…、上に固定 / 固定を解除、このフォルダーを閉じる、色（12 のパステル カラーまたは自動）、上へ移動 / 下へ移動（開いた順のとき）、専用インスタンスで開く、デスクトップにショートカット、フォルダーに表示、パスをコピー、最新の情報に更新。
新しい Markdown ファイル、新しいフォルダーツール バーの最初の 2 つのボタン（+ の付いたページとフォルダー）、またはフォルダーを右クリック → 新しい Markdown ファイル… / 新しいフォルダー…。ツリーで選んだフォルダー（ファイルを選んでいればそのフォルダー）に、すぐにディスク上で作られます。何も選んでいなければ ドキュメント\Vigia に作られ、このフォルダーは最初のときに作成されてパネルに追加されます。空いている名前が提案されます（新しいドキュメント.md、新しいドキュメント 2.md…）。Markdown の拡張子がないファイルには .md が付き、名前が見出しとして最初に入ります。新しいファイルはすぐに開き、新しいフォルダーは選ばれたままになるので、次のファイルはその中に作られます。既存のものを上書きすることはなく、使われている名前は受け付けません。2 つのボタンはどのモードでも、GitHub 表示や読み取り専用でも使えますが、ツリーのロックを解除しているとき（パネル上部の錠前）だけです。ロック中はボタンとメニュー項目が灰色になり、ポインターを置くとその旨が表示されます。
ツリーの中を右クリックファイルでは: 開く、新しいウィンドウで開く、フォルダーに表示、パスをコピー、TXT に変換（GitHub 表示での見え方どおりに、見出し、リスト、表、リンクをプレーン テキストにした .txt を隣に書き出し、Markdown ファイルはそのまま残します）。フォルダーでは: 新しい Markdown ファイル、新しいフォルダー、フォルダーに表示、パスをコピー、最新の情報に更新。どちらでも: 名前の変更（F2 でも可）と削除（Del でも可）。
削除ツリーのロックを解除しているとき（パネル上部の錠前。ロック中は削除が灰色になり、Del キーも効きません）、ファイルやフォルダーを右クリック → 削除、または選んで Del キー。ごみ箱に移動されるので、そこから元に戻せます（フォルダーは中身ごと）。ネットワーク フォルダーや USB メモリにはごみ箱がないため、そこでは完全に削除するかどうかを毎回確認します。削除の前に確認します。このウィンドウでは今後確認しないにチェックすると、そのウィンドウを閉じるまで確認しません。新しいウィンドウや、Vigía を起動し直したときは、また確認します。削除したもののタブは閉じ、お気に入りと最近使ったファイルからも外れます。開いているフォルダー自体（色の付いたブロック）はここからは削除されず、そのメニューで閉じます。
パネルのボタン2 つの矢印は名前の変更と移動を元に戻す / やり直す。錠前はドラッグ用にツリーをロック / 解除。+ はフォルダーを追加、最新の情報に更新、すべて折りたたむ / すべて展開（1 つのボタンです。開いているフォルダーがあればすべて折りたたみ、すべて閉じているときはすべてのフォルダーをすべての階層まで展開します。どちらになるかはアイコンとヒントでわかります。⋯ メニューには両方あります）、そして ⋯: 並べ替え、色、起動時に開くもの。展開は 1,500 フォルダーで止まるので、ドライブ全体のような大きなツリーでもウィンドウが固まりません。

ファイルの名前の変更と移動

ツリーでの操作はディスク上で行われます。F2 または右クリック → 名前の変更で、選んだファイルやフォルダーの名前を変えます。 ファイルやフォルダーを移動するには、パネルの見出しの錠前をクリックしてツリーのロックを解除し、フォルダーの上（またはそのフォルダー内のファイルの上）に ドラッグします。ドラッグ中は移動先のフォルダーが強調表示されます。もう一度錠前をクリックするとツリーがロックされ、マウスが滑っても何も動きません。 名前の変更と移動は、見出しの ← 矢印で元に戻し、→ でやり直せます。ツリーにフォーカスがあるときは Ctrl+Z / Ctrl+Y でも可能で、矢印のヒントに何を元に戻す / やり直すかが表示されます。開いている文書の名前が変わったり移動したりしても、 新しい場所で開いたままです（変更があれば先に保存します）。開いているフォルダーそのものはツリーから名前を変えたり移動したりはできず、 移動先にすでにある名前は受け付けません。

並べ替え、色、固定

パネルの ⋯ ボタンでフォルダーを並べ替えます: 開いた順（既定）、名前 A → Z、名前 Z → A、 更新日時の新しい順。固定したフォルダー（📌）は、固定した順に常に一番上に並びます。色: テーマカラーの濃淡 （既定: 表示 → テーマ… で選んだ色の濃淡）、マルチカラー（フォルダーごとに別の色相）、色なし。 フォルダーごとに右クリック メニューから独自の色も付けられます。

専用インスタンス

やることリストや wiki のように、ほかの作業と混ぜたくないファイルやフォルダーには、専用の Vigía を使えます。 ファイル、またはフォルダーのタイトルを右クリックして専用インスタンスで開くを選ぶか、デスクトップにショートカット（専用インスタンス）で いつもそのように開くショートカットを作ります。専用インスタンスは、独自の設定、開いているフォルダー、最近使ったファイル、サイズを持つ別のウィンドウで、 タイトル バーに名前が表示されます。もう一度開くと、別に起動せずにそのウィンドウが前面に出ます。言語、テーマ、色はメイン ウィンドウのものから始まります。 （技術的には Vigia.exe --profile "名前" "パス"。設定は %APPDATA%\Vigia\profiles\名前 にあります。）

新しいウィンドウで開くは別のもので、メインの Vigía の追加ウィンドウです。自由に使えて、メイン ウィンドウの開いているフォルダーやサイズを上書きすることはありません。

Vigía の起動時に開くもの

ファイル → 起動時のフォルダー、またはパネルの ⋯ ボタンで選びます:

オプション動作
前回のフォルダーを開き直すパネルが前回のままの状態で戻ります（既定）。
フォルダーなしで起動する毎回、空のパネルで起動します。
固定したフォルダーだけで起動する毎回、固定したフォルダーだけを表示します。たとえば、いつも作業する 1 つか 2 つのプロジェクトです。

文書は別の設定です: ファイル → 起動時にタブを復元で、前回のタブのファイルをもう一度開きます（「タブ」の章を参照）。

パネルはディスクに追従します: ほかのプログラム（たとえばエクスプローラー）が作成、名前の変更、削除したファイルやフォルダーは、すぐに現れたり消えたりします。ツリーの表示位置はそのままです（ファイルを保存してもツリーは作り直されません）。 開いているフォルダー全体が削除されたり、ネットワーク ドライブが切断されたりすると、そのブロックは使用できませんと表示されたまま残り、 フォルダーが戻れば自動的に元に戻ります。その間に削除されたファイルをクリックしても、パネルが更新されるだけです。 隠しフォルダーとツール用のフォルダー（.git、node_modules、bin、obj など）は表示されません。 最近使ったフォルダーはファイル → 最近使ったファイルに並びます。

スペル チェック最初からオンで、英語・スペイン語・日本語を同時にチェックします。どれか 1 つの言語が知っている単語は正しいとみなすので、複数の言語が混ざった文章もまとめてチェックできます。選んだどの言語にもない単語には、ビジュアル表示と Markdown 表示で赤い波線が付きます。コード（コード ブロック、`インライン コード`）とアドレスはチェックしません。表示 → スペル チェックで、開いているすべてのタブのチェックをオン/オフにします（入力した内容は失われません）。マークされた単語を右クリックすると、最初に候補が表示され（クリックで置き換え）、続いて無視(Vigía を閉じるまで)（Vigía を閉じるまで、すべてのタブでその単語をマークしません）と辞書に追加（以後ずっと正しいとみなします。このプロファイルの設定に保存されます）があります。表示 → スペル チェックの言語と辞書…（右クリック メニューの最後にもあります）では、チェックのオン/オフ、言語の選択（複数選べます）、辞書に追加した単語の一覧（選んで削除できます）、そして言語を追加…で他の言語の Hunspell 辞書（LibreOffice や Firefox と同じ、.dic ファイルと同じ場所の .aff）を追加できます。英語とスペイン語の辞書は Vigía に含まれているので、Windows に何かをインストールする必要はありません。スペイン語は一般的なものとウルグアイのもの（voseo の tenés、mirá などを知っています）の 2 つがあり、どちらも最初からオンです。日本語のスペル辞書は存在しないため（日本語のつづりをチェックするプログラムはありません）、日本語の文字はマークされず、文中の英語やスペイン語の単語がチェックされます。
1 つのウィンドウVigía の起動中に .md を開くと、2 つ目を起動せずに既存のウィンドウを前面に出し、ファイルをタブで開きます。ファイル → 新しいウィンドウなら別のウィンドウを開けます。
更新Vigía は 1 日に 1 回（すべての専用インスタンスで 1 回）新しいバージョンを確認します。ヘルプ → 更新を確認でいつでも確認できます。新しいバージョンがあれば、今すぐ更新、新機能、あとでの 1 つの質問だけで、あとは自動で進みます: 公開版のチェックサムに作者のデジタル署名があることを確かめてから、インストーラーをダウンロードして照合し（署名が無効な公開版や一致しないインストーラーは拒否し、実行しません）、すべての Vigía のウィンドウを閉じ（先に保存し、できなければ確認します）、新しいバージョンを同じオプションで静かにインストールし、ウィンドウをそれぞれのプロファイル、ファイル、タブで開き直します。閉じなかったウィンドウ（質問にキャンセルと答えたもの）があれば、何もインストールせず、ほかのウィンドウも元に戻ります。
バージョン情報ヘルプ → Vigía についてで、バージョン、作者、ライセンス、クレジットを表示します。情報をコピーでバージョンの詳細をコピーでき、問題を報告するときに便利です。
サンプル文書3 つの表示ですべての機能を見せるサンプルです。最初の起動時とヘルプ → サンプル文書から開き、ファイル → 最近使ったファイルの先頭に固定されています。そのすぐ下のサンプルを隠すで一覧から外し、ヘルプ → ［最近使ったファイル］にサンプルを表示で戻せます。無題のコピーとして開くので元のファイルは上書きされず、メニューと一緒に言語が切り替わります。

11. 言語、テーマ、ズーム

言語メニュー: English、Español、日本語。メニュー、ツール バーのヒント、ダイアログがすぐに切り替わります。 最初は Windows の表示言語に合わせます。

表示 → テーマ… でテーマのウィンドウが開きます。外観: ライト、ダーク、または Windows の設定 （設定 → 個人用設定 → 色）に合わせて自動で切り替わる自動。色: アイコンと強調表示のための 12 色のカタログです。 選んだ色は、ウィンドウ、タスク バー、デスクトップとスタート メニューのショートカット、.md ファイルなど、あらゆる場所でアイコンの背景になり、 ファイル パネルのフォルダー、チェック マーク、選択中の項目の色にもなります。既定はスカイブルーです。独自のアイコンを付けたショートカットは変わりません。

ズームは、ステータス バー右側のズーム バー（−、スライダー、+。パーセントをクリックすると 100 % に戻ります）、Ctrl + マウス ホイール、Ctrl++、 Ctrl+-、Ctrl+0 で行います。言語、テーマ、表示モード、ズームは記憶され、ウィンドウは閉じたときのサイズ、位置、 最大化の状態で開きます（その位置がどの画面にもなければ中央に開きます）。
