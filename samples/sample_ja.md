# Vigía へようこそ

これは**サンプル文書**です。自由に書き換えてかまいません。無題のコピーとして開くので、元のファイルが上書きされることはありません。手を加えた版を残したいときは、**名前を付けて保存**で保存してください。

> [!TIP]
> ツール バーの右端にある 3 つのボタン — **ビジュアル · Markdown · GitHub** — を押すか、`Ctrl+1`、`Ctrl+2`、`Ctrl+3` を押してみてください。同じ文書を 3 通りに表示します。読むだけのときは、その隣の**読み取り専用**（`Ctrl+Shift+L`）を選べば、誤って変更することはありません。

## 3 つの表示

| 表示 | ショートカット | 見えるもの |
|:--|:--:|:--|
| **ビジュアル** | `Ctrl+1` | 書式付きの文書。入力してボタンを使えば、タグは Vigía が書きます。 |
| **Markdown** | `Ctrl+2` | 左に Markdown テキスト、右にリアルタイムのプレビュー。 |
| **GitHub** | `Ctrl+3` | 読み取り専用: GitHub で表示されるとおりのページ。 |

1. 今はたぶん**ビジュアル**表示です。単語を選んで `Ctrl+B` を押すと、**太字**になります。
2. **Markdown** に切り替えると、同じ単語の両側に `**` が付いています。これがタグです。
3. **GitHub** に切り替えると、下のほうの図と数式が github.com と同じように描かれます。

## テキスト

通常のテキスト、*斜体*、**太字**、~~取り消し線~~、`インライン コード`、[GitHub へのリンク](https://github.com)。名前で書く絵文字 :sparkles: :rocket: や脚注も使えます。[^1]

- 箇条書き
  - 入れ子の項目
- [x] 終わったタスク
- [ ] まだのタスク

## フォルダー

**ファイル → フォルダーを開く…** でフォルダーを丸ごと開くと、VS Code や Obsidian のように、その中の Markdown ファイルが左側のツリーに表示されます。フォルダーはいくつでも開けて、それぞれに色が付きます。パネルの **⋯** ボタンで並べ替え、色の変更、起動時に開くものの選択ができます。ファイルをクリックすると開きます。`Ctrl+Shift+E` でパネルの表示と非表示を切り替えます。

## タブ

ファイルはそれぞれ自分のタブで開きます。`Ctrl+Tab` でタブを切り替え、`Ctrl+W` でタブを閉じます。**ファイル → 起動時にタブを復元** をオンにすると、次回の起動時に同じファイルが開きます。

---

このサンプルを **ファイル → 最近使ったファイル** に表示しないようにするには、そのすぐ下の **サンプルを隠す** を選びます（または **ヘルプ → ［最近使ったファイル］にサンプルを表示** のチェックを外します）。**ヘルプ → サンプル文書** からはいつでも開けます。

[^1]: 脚注です。GitHub 表示ではページの最後に一覧になります。
